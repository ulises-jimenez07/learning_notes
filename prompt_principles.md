# General

1. Be clear and specific
2. Consider the audience
3. Specify an output format
4. Use examples when needed
5. Use simple language
6. Test and iterate for best results

## Formula
- The input: The task
  ```
  Make me the content of a Cloud computing course in GCP
  ```
- Context
  ```
  I am a professor. I work in animation
  ```  
- Example: if we are not getting the output we want, we can use it
  ```
  You are a sentiment analysis assistant
  Analyze the sentimentimen analysizes of this tweet

  Tweet: "OMG Arsenal is the best team of all the time"
  Sentiment: Positive
  ```


## Images
1. Be specific
2. Break it down step by step
3. Call attention to parts of the image
4. Put the image first
5. Ask the model to describe the image first before doing anythin else
6. Ask the model to explain "why"
